# Voxtral-Mini-4B-Realtime-2602

Run it in the Llama app: https://llama.app

Or from the terminal:

```bash
llama serve -hf __owner__/Voxtral-Mini-4B-Realtime-2602-GGUF
```

This is a realtime (streaming) speech recognition model. See https://github.com/ggml-org/llama.cpp/pull/30629

### Source models
- https://huggingface.co/mistralai/Voxtral-Mini-4B-Realtime-2602

> [!IMPORTANT]
> This model is automatically converted using https://github.com/ggml-org/convert
